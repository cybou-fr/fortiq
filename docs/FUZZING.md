# Санитайзеры и фаззинг

Статус: **сделано 24.10.2026** (пункт 5 бэклога [аудита](AUDIT_2026-10-23.md)). Это проверка, а не гарантия: фаззер не нашёл больше ничего за отведённое время, но не доказывает отсутствие ошибок.

## Что проверяется

Всё, что FORTIQ разбирает из внешнего мира без сети и без сервера — чистые функции на Qt Core:

| Цель | Что подаётся | Что утверждается (инварианты, прерывают прогон) |
|---|---|---|
| `html`, `html-reader` | HTML веб-страницы и письма | на выходе нет `script`, `style`, `iframe`, `img`, форм и т. д.; в тегах остаются только `href` (только `http(s)`), `colspan`, `rowspan`, `start` (числа) |
| `sql-sqlite`, `sql-postgres` | текст SQL пользователя | если `readOnlyRefusal` пуст — ровно ≤ 1 закрытый оператор, без мета-команд клиента, ключевое слово чтения |
| `db-profile`, `db-parsers` | профиль БД; CSV/quote/схема/ответ проверки роли | не падает; `quoteIdentifier` всегда даёт идентификатор в кавычках |
| `url`, `policy` | адрес из строки Navigateur, ссылки, ответ `getent` | нормализованный адрес — только `http(s)`, без учётных данных и управляющих символов; ссылка разрешается в `http(s)` или в пустое; заблокированный адрес не получает `pinIp` |
| `mail-send` | адреса, тема, тело | в заголовках нет `CR`, каждая строка — заголовок или продолжение, `Bcc` не попадает в письмо; каждый получатель в скрипте идёт в одинарных кавычках после `--` |
| `mail-account` | пароль, имена вложений, ответы сервера | имя вложения без разделителей путей и управляющих символов, не пустое |
| `mail-info`, `net-system` | JSON `notmuch`, вывод `ip`, `ss`, `ps`, `systemctl`, `/proc` | не падает, без неопределённого поведения |

Не охвачено: разбор Logs (`LogsAnalysis` вплетён в контроллер), Markdown (использует `QTextDocument`), SSH-слой, QML.

## Три уровня

1. **`fortiq_fuzz_smoke`** — обычный `ctest` на всех платформах (в том числе Windows MSVC): все сиды (`fuzz/seeds`, фикстуры `tests/fixtures`) через все цели + 4000 мутаций с фиксированным зерном. Ловит регрессию, не ищет новое.
   `fortiq_fuzz_smoke <каталог сидов>... --iterations N --seed S`; `--list` — перечень целей; переменная `FORTIQ_FUZZ_LAST=файл` хранит текущий вход (на случай аварийного завершения).
2. **Модульные тесты под ASan + UBSan** — на одноразовом Debian с clang: `cmake -DFORTIQ_SANITIZE=ON -DBUILD_TESTING=ON`, затем `ctest -E "layout|brand|ssh_integration"` (`QT_QPA_PLATFORM=offscreen`, `ASAN_OPTIONS=detect_leaks=0`).
3. **libFuzzer** — `sh tool/fuzz_linux.sh [секунд на цель] [каталог сборки]` (нужны `clang`, `cmake`, `ninja`, `qt6-base-dev`, `libclang-rt-dev`; сам скрипт ничего не устанавливает). Первый байт входа выбирает цель; находки (`crash-*`, `oom-*`, `timeout-*`) складываются в `<сборка>/artifacts`; код возврата ≠ 0, если они есть.
   Воспроизведение: `<сборка>/fortiq_fuzz <файл находки>`.

MSVC для x64 здесь не используется: рантайм ASan для x64 не установлен в Visual Studio, поэтому санитайзеры идут на Linux/clang.

## Что нашли

- **Неопределённое поведение при разборе ответа сервера** (`SystemInfo.cpp`, потом ещё 12 мест в `NetworkInfo`, `MailInfo`, `LogsAnalysis`): приведение `double` (NaN, `1e40`, бесконечность из JSON/текста) к `qint64`. Исправлено общей функцией `toInt64` ([SafeCast.h](../src/core/SafeCast.h)): NaN → 0, вне диапазона → насыщение.
- **Чтение за границей литерала в тесте** (`BrowserTest::binaryBodiesAreCarriedByLength`, найдено ASan): тело в 23 байта объявлялось как 25. Это ошибка теста, не продукта; исправлена.
- Тест `LocalDocumentTest` проверял путь Windows на Linux — сделан зависящим от платформы.
- Два инварианта фаззера оказались слишком строгими и были исправлены в самом фаззере: `javascript:` внутри *пути* https-ссылки безвреден; адрес с `&`, `;`, `$`, `'` допустим по RFC 5322 и всегда идёт в скрипт в одинарных кавычках после `--`.

## Что не проверено

- Время фаззинга ограничено: по 150 с на каждую из 12 целей (≈ 100–400 тысяч запусков на цель) — этого мало для вывода о стойкости. Перед выпуском стоит дать часы.
- Нет постоянного корпуса и нет запуска libFuzzer в CI (`.github/workflows/ci.yml` запускает только smoke).
- ASan/UBSan для кода, зависящего от libssh2 и QML (SSH-сессия, контроллеры), и для Android не запускались.
