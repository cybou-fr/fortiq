# Архивный снимок README — выведен из обращения

**Этот файл больше не является документацией FORTIQ.** Ранее в нём были
устаревшие предложения о прямой IMAP/SMTP-почте и независимых Local/Account
приложениях. Они **отменены** решением 11.10.2026.

**Обязательное правило FORTIQ:** GUI frontend → SSH → консольная программа
на Linux-сервере (готовая либо наша `fortiq-*`). Mail и все остальные
рабочие операции выполняются через SSH; прямые клиентские SMTP/IMAP
запрещены. Lemon Squeezy — отдельный служебный контур лицензирования.

Действующая документация:
- [SSH_FRONTEND_CONTRACT](../SSH_FRONTEND_CONTRACT.md) — главный архитектурный контракт
- [README](../../README.md) — актуальные возможности
- [PRODUCT_SCOPE](../PRODUCT_SCOPE.md) — позиционирование
- [ARCHITECTURE](../ARCHITECTURE.md) — архитектура
- [DEVELOPMENT_MATRIX](../DEVELOPMENT_MATRIX.md) — план разработки

Старый снимок доступен в **истории Git**, если требуется исторический анализ,
но не должен использоваться при реализации или генерации сайта.
