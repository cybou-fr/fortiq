# FORTIQ — Desktop Shell: реализация и сверка с эталоном

**Статус на 21.10.2026: первый срез R0.2 Desktop Shell в исходниках; визуально НЕ принят.**
Контракт внешнего вида — [UI SPEC v1](UI_SPEC_V1.md); функциональность окон — [Smart Files](SMART_FILES_SPEC.md)
и (позже) [Logs](LOGS_INTELLIGENCE_SPEC.md). Этот документ фиксирует, что сделано, как это
проверять и чем текущий рендер расходится с эталоном.

## Что реализовано

QML-модуль `Fortiq.Shell` (`qml/shell/`) воспроизводит композицию 1536×1024 в координатах эталона:

| Регион UI_SPEC §1 | Компонент | Поведение вне фикстуры |
| --- | --- | --- |
| TOP | `TopBar.qml` | имя выбранного сервера или «Aucun serveur», локальные часы |
| RAIL | `AppRail.qml` | «Fichiers» открывает окно Files; остальные пока ничего не запускают |
| CLOCK | `ClockWidget.qml` | локальное время; погода — «Météo indisponible» (нет серверного источника) |
| FILES / FILES SIDEBAR | `FilesWindow.qml`, `ConnectPane.qml` | без подключения — форма SSH с проверкой отпечатка; после — реальный листинг SFTP R0.1 |
| LAUNCHER | `LauncherPanel.qml` | приложения FORTIQ; «Recommandé» пуст до появления реальных данных; закрыт по умолчанию |
| BROWSER | `BrowserWindow.qml` | только визуальная оболочка с баннером «non disponible»; сети нет |
| CONTROL | `ControlCenter.qml` | плитки, ползунки, медиа и агенда приглушены и подписаны «indisponible» |
| WORKSPACES | `WorkspaceSwitcher.qml` | выбор только в памяти, не сохраняется |
| DOCK / TRASH | `Dock.qml` | кнопка приложений открывает/закрывает launcher |

Стекло: `Glass.qml` — размытый срез обоев (`ShaderEffectSource` + `MultiEffect`) с тонировкой и
1px кромкой; `blurEnabled: false` — непрозрачный запасной вариант. Иконки нарисованы примитивами:
сторонних логотипов (Firefox, VS Code, Spotify и т. п.) в коде нет.

Холст масштабируется в окне равномерно. Адаптации UI_SPEC §4 для планшета и узкого экрана
**не реализованы**.

## Эталонная фикстура и захват

`--reference-fixture` включает только визуальную сцену эталона: часы 13:45, погода Перпиньяна,
образцы файлов, открытые launcher/control center/browser. Это образцы, а не данные сервера.

`--screenshot <png>` отключает масштабирование High-DPI, ставит окно 1536×1024 без рамки,
ждёт 1,5 с и сохраняет кадр. Цель `fortiq_shell_preview` собирает только оболочку (без libssh2):

```sh
cmake -S . -B build-preview -G Ninja -DFORTIQ_SHELL_PREVIEW_ONLY=ON -DCMAKE_PREFIX_PATH=<Qt>/mingw_64
cmake --build build-preview
python3 tool/compare_shell_screenshot.py --run build-preview/fortiq_shell_preview.exe
```

Скрипт проверяет SHA-256 эталона, снимает кадр и пишет в `build-preview/compare/`:
`side-by-side.png`, `diff.png` (разница ×3), `overlay.png`, `report.json` с метриками по регионам
§1. Метрики — материал для настройки, не вердикт приёмки (§6 требует ревью владельца).

## Блокеры точного совпадения

1. **Обои.** В репозитории есть только составной скриншот, отдельного файла обоев нет. Нужен
   оригинал или лицензированный эквивалент той же композиции (UI_SPEC §2); до этого рисуется
   процедурная заглушка `Wallpaper.qml`, а `--wallpaper <file>` подставит файл, когда он появится.
   Вырезать обои из эталона нельзя: в них останутся следы интерфейса.
2. **Иконки.** Нужен согласованный набор оригинальных иконок FORTIQ; часть Unicode-глифов в
   Segoe UI отображается квадратами.
3. **Шрифт.** Сейчас системный Segoe UI; гарнитура эталона не установлена.
4. **Планшет/узкий экран** (§4) и проверка на Android не выполнялись.
5. **Полное приложение** с libssh2 в этой итерации не собиралось; проверена только цель
   `fortiq_shell_preview`.
