Не проверено, есть ли обновление 6.140.x с исправлениями безопасности: сверить с wiki.qt.io/QtWebEngine/ChromiumVersions и Qt Maintenance Tool. **B3 закрыт для libssh2 и OpenSSL, открыт для Qt WebEngine/Chromium.**

- Вывод: подтвердить, что поставляемый движок **актуален**, нельзя. На ветке 6.11.x уже указан более высокий патч-уровень (155.x против нашего 152.x), а Chromium регулярно получает исправления эксплуатируемых уязвимостей; движок исполняет произвольный JavaScript из сети. Закрыть B3 по Chromium можно только обновлением Qt WebEngine до выпуска с актуальным патч-уровнем (через Qt Maintenance Tool, с последующим живым прогоном `fortiq_engine_it`) либо исключением движка из пакета.
- Рекомендация (решение владельца): в первую alpha **не включать** Qt WebEngine. Это убирает самую большую сетевую поверхность, около 280 МБ из пакета и блокирующие живые тесты шлюза и движка (порт 8099). Режим «Web Reader» (`curl` на сервере, без JavaScript) остаётся в preview.
