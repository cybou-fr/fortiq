# SBOM и обзор уязвимостей зависимостей (S-11)

Статус на 25.10.2026. Это **инвентаризация и ручной обзор**, а не автоматическое сканирование: автоматического источника CVE в проекте нет, обзор нужно повторять при каждом выпуске.

## Что есть

- [`docs/sbom/fortiq.cdx.json`](sbom/fortiq.cdx.json) — SBOM в формате CycloneDX 1.5, 13 компонентов для Windows x64 и Android arm64, с PURL, CPE, лицензией и (для DLL Windows) SHA-256. Файл детерминирован (без метки времени), поэтому смена зависимости видна как diff.
- `python tool/make_sbom.py --output docs/sbom/fortiq.cdx.json` — собрать заново; `--check docs/sbom/fortiq.cdx.json` — упасть, если машина (vcpkg, Qt, libvterm) уже не совпадает с закоммиченным файлом; `--self-test` — проверка самого инструмента (входит в `tool/ci_check.py`).
- Источники данных: `installed/vcpkg/status` обоих деревьев vcpkg (точные версии и ревизии портов), `Qt6ConfigVersion.cmake`, версия IFW, `third_party/libvterm`. Компоненты, версию которых нельзя прочитать с машины (Mesa llvmpipe, d3dcompiler_47, среда выполнения MSVC, Gradle-зависимости Qt for Android), внесены с `fortiq:version-known = false`: отсутствие версии не означает отсутствия уязвимостей.

## Обзор CVE по точным версиям (25.10.2026)

Источники: страницы проекта OpenSSL и зависимостей, объявления Qt, публикации по libssh2 (ссылки ниже). Обзор выполнен по тексту этих страниц; страницы длинные и частично усечены, идентификаторы и «исправлено в» перепроверять по первоисточнику перед выпуском.

| **libssh2** — раньше 1.11.1 (последний релиз), **теперь коммит master `6e7b207`** (24.10.2026, все 88 проверок CI проекта зелёные) через собственный порт [`third_party/vcpkg-overlay-ports/libssh2`](../third_party/vcpkg-overlay-ports/libssh2/README.fortiq.md) | **CVE-2026-55200** (критический, запись за границу в `transport.c`; затрагивал 1.11.1 и раньше; публичный PoC), **CVE-2026-55199**, **CVE-2025-15661**; исправления есть только в master (коммит `97acf3d` — проверка длины пакета — входит в выбранный коммит; от него 621 коммит безопасности и надёжности) | **Прямая:** пакеты читаются при рукопожатии **до** проверки отпечатка хоста | **Закрыт 25.10.2026 (R14), с оговорками:** сборка идёт из исправленного исходника, но это не релиз — пока вышедшего релиза с исправлениями нет; повторить обзор при выходе релиза и вернуться на порт vcpkg |

## Правила

1. Перед каждым выпуском: `make_sbom.py --check`, затем повторить этот обзор по версиям из SBOM и записать дату.
2. Зависимость не обновляется молча: новая версия — отдельный коммит с повторным прогоном тестов S-1 (рукопожатие), S-3…S-5 (Files), `fortiq_publication` и живых наборов.
3. Версия с известной критической уязвимостью в достижимом коде блокирует выпуск (R14 закрыт сборкой из master; снять оговорку можно, когда выйдет релиз libssh2 с исправлениями).
