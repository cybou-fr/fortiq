# Состав релиза 1.0

Статус на 26.10.2026 (Production Sprint 1, шаг 2 [плана выпуска](PRODUCTION_READINESS.md)). Документ замораживает, **что входит в 1.0 и в каком качестве**. Он не утверждает, что функции готовы: готовность доказывают гейты G2–G6 ([PRODUCTION_READINESS](PRODUCTION_READINESS.md)). Источники фактов: [DEVELOPMENT_MATRIX](DEVELOPMENT_MATRIX.md), [QT_MIGRATION](QT_MIGRATION.md), [STABILIZATION_PLAN](STABILIZATION_PLAN.md), результаты тестов.

Три уровня:
- **supported** — входит в стабильный контракт 1.0; дефект блокирует выпуск; у функции есть сценарий приёмки и автоматическое свидетельство;
- **preview** — работает в описанных пределах, помечена в интерфейсе и документации как предварительная; известные ограничения перечислены, дефект не блокирует выпуск, если ограничение честно показано пользователю;
- **not supported** — не входит; не рекламируется; наличие в старом [ROADMAP](ROADMAP.md) не блокирует выпуск.

Платформы: **Windows x64 — основная** (выходит, когда закрыт G4). **Android arm64 — beta**, пока G5 (физическое устройство) не закрыт; он не задерживает Windows 1.0.

## Таблица функций

| Функция | Уровень | Сценарий приёмки | Свидетельство сейчас | Известные ограничения |
|---|---|---|---|---|
| **SSH-подключение** (пароль, ключ, закрепление отпечатка SHA-256, постоянные сессии, профили серверов, защищённое хранение секретов) | supported | вход на чистый Debian; смена ключа хоста блокирует вход до явного решения; устаревшие алгоритмы отвергаются; пароль/фраза ключа не попадают в журналы и память после использования | живой набор `fortiq_ssh_it` (57 тестов), `obsoleteAlgorithmsAreRefused`, `secretsLeaveNoCopiesInMemory`, `fortiq_publication`; libssh2 `6e7b207` + OpenSSL 3.6.5 | ssh-agent не реализован; два сервера не смешиваются — `twoHostsNeverMix` выполнен 26.10.2026; Android Keystore проверен только самотестом на эмуляторе |
| **Files** (обзор, превью, загрузка/выгрузка, Trash, переименование, редактор, поиск, постраничный показ папок >5000 записей) | supported | работа в каталоге с пробелами и Unicode; конфликт имён; обрыв SSH во время передачи (`unknown`, без автоповтора записи); сохранение при изменённом файле на сервере; каталог на 25 000 записей | живые тесты передач/Trash/save/конфликтов, `hugeFolderIsPagedNotRefused`; базовые замеры [PERFORMANCE_BASELINE](PERFORMANCE_BASELINE.md) | модель QML не виртуализирована (до 50 000 записей на экране); время построения сетки на таких объёмах не измерено; визуальная приёмка не проведена |
| **Terminal** (PTY, libvterm, история Bash, обратное давление) | supported | интерактивная сессия, Ctrl+C под потоком вывода, изменение размера, обрыв | `fortiq_terminal_sequences`, живые `terminalBackpressureStopsReadingNotTyping` и др. | потолок ≈100 000 прокрученных строк/с ([PERFORMANCE_BASELINE](PERFORMANCE_BASELINE.md)); tmux-интеграция не сделана |
| **Logs** (journald, файлы /var/log, период и важность, прямой эфир, группы повторов, инспектор) без AI | supported | события службы с реального Debian; недоступный источник = ошибка, не пустой список | `fortiq_logs`, живой reader-тест через WSL | корреляция «первого среза»; полный контракт [LOGS_INTELLIGENCE_SPEC](LOGS_INTELLIGENCE_SPEC.md) не закрыт — это целевой документ |
| **System / Processes / Network / Disks** (только чтение) | supported — как обзорные, **только чтение** | значения совпадают с `systemctl`/`ps`/`ip`/`lsblk` на тестовом Debian; недоступная команда = ошибка | `fortiq_system`, `fortiq_network`, `fortiq_disks`, живые тесты | никаких изменяющих действий (остановка служб, kill, правка сети, операции с дисками) — **not supported** |
| **MDok / Markdown** (серверные черновики, экран конфликта, поиск/замена, подсветка, предпросмотр) | supported | правка файла с обрывом связи: черновик на сервере, восстановление, конфликт с diff | `fortiq_markdown`, `fortiq_highlighter`, живой `mdokServerDraftAndConflict` | PDF не реализован; черновик для нового несохранённого документа не делается |
| **Mail** (notmuch: чтение, теги, отправка msmtp) | **preview** | чтение и теги на сервере с notmuch; отправка с честным исходом «неизвестно»; Files → исходящие вложения (Python 3, 10 файлов / 10 MiB); враждебный MIME | `fortiq_mail`, `fortiq_mailsend`, живой `mailSurvivesHostileMime` (20 писем) | зависит от серверных notmuch/mbsync/msmtp; пароли почты хранятся на сервере в открытом виде в его конфигурации (R3, смягчено правами 0600); без вложений-«открыть» |
| **Databases** (SQLite, PostgreSQL, только чтение) | **preview** | запрос с лимитами строк/времени; отмена; `psql`-процесс не остаётся | `fortiq_db`, живой `databaseAppIsReadOnlyAndBounded` | защита от записи — слои, **не граница безопасности**; MariaDB, запись — not supported |
| **Browser / Web Reader** (`curl` на сервере, без JavaScript) | **preview** | страница, редиректы, режим чтения, блокировка внутренних адресов с подтверждением, DNS-rebinding | `fortiq_browser` (108), живой `browserSurvivesDnsRebinding` | без JS/CSS/cookies, формы — только простые GET-формы поиска; поиск по словам (Bing, DuckDuckGo, Wikipédia, Google); многие сайты и поисковики отдают страницу-заглушку без JavaScript (Google, антиботы); Android на устройстве не проверялся; HTML-очистка ≈1,2 МБ/с (в рабочем потоке); **движок с JavaScript в 1.0 не входит** (решение владельца не менялось): шлюз (`fortiq_gateway`, `fortiq_gateway_it`) и окно Qt WebEngine для Windows (`fortiq_engine`, `fortiq_engine_it` с тестом утечек, 27.10.2026) готовы как кандидат в preview Windows — только после решения владельца и юридической проверки лицензий Chromium; Android: окно на системном WebView (27.10.2026) проверено только на эмуляторе (`tool/android_browser_check.py`), на устройстве не проверялось, остаточный риск WebRTC — решение владельца; Linux не проверен |
| **Desktop Shell** (окна, dock, launcher, control center) | supported после визуальной приёмки (G6) | сверка с эталоном 1536×1024 и адаптация на реальных экранах | `fortiq_layout`; `tool/compare_shell_screenshot.py` | **визуально не принят** ([SHELL_FIDELITY](SHELL_FIDELITY.md)) |
| Android arm64 (APK) | **beta** | G5: физическое устройство | эмулятор FortiqTablet: вход, Files, SAF, поворот, IME, Back | физическое устройство не проверено; релизная подпись APK не настроена |
| Windows: установщик и ZIP | supported после G4 | чистая Windows 11 без Qt SDK: установка, запуск, обновление поверх, удаление | пакет собирается и проходит `check_third_party.py`; **чистая машина проверяется владельцем** | не подписан (нет сертификата); служебный `FORTIQ-maintenance.exe` не подписан |

## Not supported в 1.0

AI (`ai`/llama.cpp); отдельные приложения Search, Editor (редактирование есть внутри Files), Viewer/PDF, Server Setup; управление процессами и службами (kill/restart); изменение сети и дисков; Messengers; полноценный веб-движок и JavaScript; декларативный SDK и маркетплейс компонентов; автоматическое обновление клиента (см. [RELEASE](RELEASE.md): вручную, подписанным установщиком); любые прямые сетевые подключения клиента, кроме SSH к выбранному серверу.

## Как этот документ меняется

Перевод функции из preview в supported — только с новым сценарием приёмки и свидетельством; понижение уровня — немедленно при найденном дефекте безопасности. Перед выпуском таблица сверяется с [PRODUCTION_READINESS](PRODUCTION_READINESS.md) (G1).
