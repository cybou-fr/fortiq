ONE CLEAR ARCHITECTURE

A desktop here.
A Linux system there.

FORTIQ renders locally. The server remains the source of working data and computations. SSH, SFTP and verified Linux tools bridge the two. No custom Linux daemon, remote GNOME installation or pixel-streaming session required.

No direct work-data network fallback. The optional browser requires separate proxy-security validation.
