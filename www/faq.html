FAQ

Questions,
answered plainly.

Short answers, consistent with the project documents.

Is this a remote desktop like VNC or RDP?

No. FORTIQ does not stream a screen. It is a native app that draws its own interface locally and runs existing Linux tools on the server over SSH. The server needs no graphical desktop.

What do I have to install on my server?

Nothing from FORTIQ. There is no agent and no daemon. Some apps use tools such as notmuch, curl or psql if you want those apps.

Which systems does it run on?

Windows x64 is the primary platform. Android arm64 is in beta. The server is Debian or Ubuntu.

Can I download it today?

Not yet. FORTIQ is an engineering prototype, and the repository is private until the pre-publication audit is done.

Does it need AI?

No. Every everyday tool works without it. An optional offline assistant is planned and is not available today.

Does it send data anywhere else?

No. The client connects only to the SSH server you choose. It has no analytics and does not check for updates by itself.

Can it change my server?

Files can create, rename and delete in your own folders, and Terminal is a real shell. System, Databases and Logs are read-only. FORTIQ does not run suggested commands on its own.

Does the browser run JavaScript?

No. It is a safe text reader built on curl running on your server, and it is labelled as preview.

Why does Windows warn about the installer?

The installer is not code-signed yet because the project has no certificate. Expect a SmartScreen warning until that changes.

Which languages does the product speak?

The desktop interface is currently in French. This site is in English, French and Russian.
