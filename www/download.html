In development

Windows

x64 · primary platform

  • Per-user installer: no administrator rights, installs into your profile with a Start menu shortcut and an uninstaller.
  • A portable ZIP is produced as well.
  • Not signed yet: Windows SmartScreen will warn, because there is no code-signing certificate.
  • Installation on a clean Windows 11 machine is not yet tested.
  • No automatic updates: install a newer version over the old one.
Beta, in testing

Android

arm64 · beta

  • Not yet tested on a physical device.
  • The release APK is not signed yet.

Requirements

What your server needs

FORTIQ adds nothing to your server. These are the things it expects to find.

  • A Debian or Ubuntu host

    Reachable over SSH with a password or a key. A VPS, a machine at home or WSL all work.

  • Core apps

    Files, Terminal, Logs, MDok and System rely on standard tools that a typical Debian or Ubuntu already has.

  • Optional tools

    Mail needs notmuch, mbsync and msmtp configured. Browser needs curl. Databases need sqlite3 or psql.

First run

What the first minute looks like

Once a build is available.

  • 1 · Add a server

    Enter host, user and a password or key.

  • 2 · Verify the fingerprint

    Compare the shown SHA-256 fingerprint with your server. FORTIQ pins it.

  • 3 · Open your desktop

    Files, Terminal, Logs and more, all on the one connection.
