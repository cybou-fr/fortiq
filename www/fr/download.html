Pas encore public.
Voici le plan.

FORTIQ est un prototype d'ingénierie. Il n'existe pas de téléchargement public aujourd'hui, et nous préférons le dire plutôt que distribuer quelque chose de non qualifié.

Pas encore de version publique

Le dépôt reste privé jusqu'à la fin d'un audit de pré-publication. Quand les premières versions paraîtront, cette page proposera les installateurs, les sommes de contrôle et le code source.

En développement

Windows

x64 · plateforme principale

  • Installateur par utilisateur : sans droits d'administrateur, installé dans votre profil avec un raccourci du menu Démarrer et un désinstallateur.
  • Une archive ZIP portable est également produite.
  • Pas encore signé : Windows SmartScreen avertira, faute de certificat de signature de code.
  • L'installation sur une machine Windows 11 vierge n'est pas encore testée.
  • Pas de mise à jour automatique : installez la nouvelle version par-dessus l'ancienne.
Bêta, en test

Android

arm64 · bêta

  • Une version de débogage passe les contrôles de connexion, de Fichiers et du sélecteur de stockage dans un émulateur.
  • Pas encore testée sur un appareil physique.
  • L'APK de version n'est pas encore signé.

Prérequis

Ce dont votre serveur a besoin

FORTIQ n'ajoute rien à votre serveur. Voici ce qu'il s'attend à y trouver.

  • Un hôte Debian ou Ubuntu

    Joignable en SSH avec un mot de passe ou une clé. Un VPS, une machine chez vous ou WSL conviennent.

  • Applications de base

    Fichiers, Terminal, Journaux, MDok et Système s'appuient sur des outils standard qu'un Debian ou Ubuntu typique possède déjà.

  • Outils facultatifs

    Le courrier exige notmuch, mbsync et msmtp configurés. Le navigateur exige curl. Les bases de données exigent sqlite3 ou psql.

Premier lancement

La première minute

Dès qu'une version sera disponible.

  • 1 · Ajouter un serveur

    Saisissez l'hôte, l'utilisateur et un mot de passe ou une clé.

  • 2 · Vérifier l'empreinte

    Comparez l'empreinte SHA-256 affichée avec celle de votre serveur. FORTIQ l'épingle.

  • 3 · Ouvrir votre bureau

    Fichiers, Terminal, Journaux et plus, sur une seule connexion.

Code source

Logiciel libre, GPL-3.0

FORTIQ est un logiciel libre sous GNU GPL v3.0, destiné à être publié intégralement sur GitHub.

  • Ce que vous recevrez

    Le code source et les scripts de construction de chaque version binaire, le texte de la licence et les mentions des composants tiers.

  • Quand

    Après l'audit de pré-publication des secrets et des droits sur les ressources. D'ici là, le dépôt reste privé.
