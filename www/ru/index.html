ОДНА ПОНЯТНАЯ АРХИТЕКТУРА

Рабочий стол здесь.
Linux — там.

FORTIQ рисует интерфейс локально, а сервер остаётся источником файлов и вычислений. Связь через SSH, SFTP и проверенные Linux-инструменты. Не нужны собственные серверные агенты, GNOME на сервере или трансляция экрана.

Нет прямого сетевого fallback для рабочих данных. Браузер появится только после проверки безопасного проксирования.

СОСТОЯНИЕ РАЗРАБОТКИ

Архитектура определена. Продукт создаётся.

В исходниках первого Qt/C++ прототипа есть SSH-подключение и просмотр каталогов по SFTP. Сборки Windows/Android, точный UI по утверждённому эскизу, расширенный Smart Files и Logs ещё требуют реализации или проверки.
